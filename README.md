# AI

个人 AI 学习仓库。每个知识点一个分支，分支内按主题分目录存放代码与笔记。

## 分支约定

- `main`：稳定基线，只保留已经学完/整理好的内容
- 每个学习主题一个分支，直接用主题名（如 `deepeval`、`langchain`、`rag`）

## 分支内的目录结构

```
<主题>/
├── README.md      # 该主题的学习笔记与进度
├── src/           # 实践代码
├── tests/         # 测试 / 评测用例
└── data/          # 示例数据
```
